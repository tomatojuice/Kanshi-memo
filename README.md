# 必読漢詩集 (Kanshi-syu)

2015年に公開したAndroidアプリを、最新技術（React Native / Expo）で11年越しにフルリメイクしました。

時代を超えて響く名作の数々を、現代語訳とシンプルな解説で掲載しています。

漢詩に興味がある方にぜひ使っていただきたいアプリです。

[🇨🇳 简体中文 (README_CN.md)](./README_CN.md) | [🔒 プライバシーポリシー (POLICY.md)](./POLICY.md)

## ✨ アプリの特徴
- **厳選された名作を収録:** 李白、杜甫、白居易など、歴史に名を残す詩人たちの代表作を網羅。
- **日中バイリンガル対応:** OSの言語設定に合わせて日本語・中国語を自動切替。
- **マイメモ機能:** 詩を読んで感じたことや独自の解釈をローカルに永続保存。
- **完全オフライン対応:** 通信環境がない場所でもすべての漢詩と解説を閲覧可能。

## 🛠️ 技術スタック
- Framework: React Native / Expo (Expo Router)
- Language: TypeScript
- Landing Page: Firebase Hosting
