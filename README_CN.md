# 必读汉诗集 (Kanshi-syu)

超越时代的经典名篇，现代汉语翻译与详细解析。为您带来古典诗词的魅力。
本应用是基于2015年发布的Android版本，使用最新技术（React Native / Expo）历时11年进行的全面重制版。

[🇯🇵 日本語 (README.md)](./README.md) | [🔒 隐私政策 (POLICY.md)](./POLICY.md)

## ✨ 应用特点
- **精选名篇:** 收录李白、杜甫、白居易等著名诗人的代表作。
- **中日双语支持:** 根据手机系统语言自动切换。
- **我的笔记功能:** 随时记录您的感悟和独到见解（本地永久保存）。
- **完全离线支持:** 无需网络即可阅读所有诗词与解析。

## 🛠️ 技术栈
- Framework: React Native / Expo (Expo Router)
- Language: TypeScript
- Landing Page: Firebase Hosting
